# HARI HARAN A — Enterprise Personal Portfolio

> **Full Stack Developer • Software Engineer • Data Analyst • Graphic Designer**
> 
> A premium, MNC/enterprise-grade personal portfolio engineered with Next.js 14, TypeScript, Tailwind CSS, Framer Motion, and Lucide React. Inspired by the editorial storytelling, dark architectural design system, and electric purple innovation accents of global enterprise technology leaders.

- **Authoritative Editorial Visual Language**: High-contrast black (`#000000`), deep charcoal (`#0A0A0A`, `#111111`), crisp white, and vivid electric purple accents (`#A100FF`, `#7C3AED`).
- **Verified Resume Data**: Exact employment timeline (Techzon Wide, KIEYVERSE, Dot Com Infoway, Mita IT Automations), academic credentials (SSM Institute of Engineering & Technology, CGPA: 8.6/10), and metrics (32% latency reduction, 99.9% uptime, 88% test coverage).

- **Deep-Dive Engineering Projects (6)**:
  1. **KIEYVERSE** — Corporate Digital Marketing Web Platform ([GitHub](https://github.com/Hari-Haran-A-07/kiey-verse.in) • [Live Demo](https://kiey-verse.in))

  4. **Real-Time V2V System** — Vehicle-to-Vehicle Socket Telematics
  5. **Social Content Scheduler** — Strategy & Multi-Format Content Scheduling Platform
  6. **Agri-Commerce Platform** — Produce Exchange with Predictive Weather Analytics
- **Verified Certificate Viewer**: Integrated fullscreen credential viewer showcasing official Dot Com Infoway internship certificate.
- **Interactive In-App Resume Generator**: Modal with live formatted resume, print/save to PDF option, and plaintext copy.

## 🚀 Quick Start & Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Production Build
```bash
npm run build
```

### 4. Start Production Server
```bash
npm run start
```

### 5. Lint
```bash
npm run lint
```
